# Portafolio de proyectos

![stack: Markdown](https://img.shields.io/badge/stack--Markdown-0d9488?style=flat-square) ![IA: asistido](https://img.shields.io/badge/IA--asistido-6366f1?style=flat-square)

Repositorio indice que describe el perfil profesional y enlaza los proyectos del portafolio.

**Tipo:** Repositorio de documentacion · **Complejidad:** Principiante

## Problema que resuelve

Concentrar en un solo lugar los enlaces, el perfil y el estado de los proyectos, en lugar de repartirlos por multiples repositorios.

## Solucion implementada

Documento Markdown con la presentacion profesional por areas y la relacion de proyectos con su tecnologia.

### Funcionalidades principales

- Indice de proyectos clasificado por area
- Perfil profesional y areas de trabajo
- Enlaces a repositorios y demostraciones

## Stack

- Markdown

## Estructura

```
README.md   # indice y perfil
LICENSE
```

## Puesta en marcha

```bash
# No requiere ejecucion: es un documento Markdown
```

## Complejidad del proyecto

**Nivel: Principiante** — Repositorio de documentacion, sin codigo ejecutable.

El nivel describe la complejidad tecnica del proyecto, no el grado de dominio de quien lo escribio.

## Despliegue

Repositorio de documentacion; no genera una pagina web.  
El codigo fuente esta disponible en este repositorio.

## Transparencia sobre IA

Este proyecto se desarrollo con asistencia de inteligencia artificial (generacion de codigo,
revision y documentacion). El codigo fue leido, ejecutado y probado manualmente. No se declaran
clientes, metricas ni resultados que no puedan verificarse.
