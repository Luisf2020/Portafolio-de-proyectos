## Protección del código

🔒 **El código fuente de estos proyectos se mantiene privado.** Este repositorio publica únicamente información de presentación y enlaces a demostraciones funcionales.

- No se distribuye el código fuente desde este repositorio.
- Los proyectos se muestran mediante demos públicas para fines de portafolio y evaluación profesional.
- El contenido, diseño, documentación y software original están sujetos al aviso de propiedad intelectual incluido en este repositorio.
- Una demo web pública puede exponer recursos del frontend al navegador; la lógica sensible debe mantenerse en backend/servicios privados.

## Nota para reclutadores y colaboradores

Si necesitas revisar arquitectura, fragmentos técnicos o una demostración guiada de un proyecto específico, puedes solicitar acceso o información adicional directamente al autor.
